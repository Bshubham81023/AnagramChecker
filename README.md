# 🔤 Anagram Checker in Java

This Java console application checks whether two input strings are **anagrams** of each other or not, without using any built-in sorting or comparison methods.

An **anagram** is a word or phrase formed by rearranging the letters of another, using all original letters exactly once.

---

## 🛠 Features

- Takes two strings as input from the user.
- Sorts characters of both strings manually (without using `Arrays.sort()`).
- Compares characters manually to check if they form an anagram.
- Provides clear output messages for user interaction.

## 📦 How to Run the Project

### 🔧 Requirements

- Java JDK (version 8 or above)
- Text editor or IDE (like VS Code, IntelliJ IDEA, Eclipse)

### ▶️ Steps to Run

1. Clone or download this repository.
2. Open a terminal and navigate to the project directory.
3. Compile the Java file:

   ```bash
   javac AnagramChecker.java
   ```

4. Run the program:

   ```bash
   java AnagramChecker
   ```
